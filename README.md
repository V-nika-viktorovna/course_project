# Проект "Обучение"

## Описание:

Курсовой проект к третьему модулю "Библиотеки для Python разработчика" 
Данный проект создан при прохождении обучения в онлайн-школе SkyPro.

Проект содержит следующие функции:

1. time_of_day() модуль utils.
Функция определяет впемя суток (утро, день, вечер, ночь).

2. filеter_df_date() модуль utils.
Функция фильтрует полученный DataFrame по дате.
Возвращает отфильтрованный DataFrame, в котором транзакции с начала месяца и по введенную дату

3. get_cards_numbers() модуль utils.
Функция принимает DataFrame и возвращает список всех номеров карт, которые есть в DataFrame

4. get_data_cards() модуль utils.
Функция принимает DataFrame и список карт, которые есть у пользователя.
Возвращает список словарей с данными по каждой карте
   - последние 4 цифры номера карты,
   - расход по данной карте,
   - кешбек по данной карте.  

5. get_top_five_transactions() модуль utils.
Функция принимает DataFrame с транзакциями, фильтрует его по суммне операции.
    Возвращает список словарей с пятью наибольшими тратами, содержащими данные:
    - дату операции,
    - сумму операции,
    - категорию операции,
    - описание операции

6. get_exchange_rate() модуль views.
Функция возвращает список со словарями курса валют имеющихся в файле 'user_settings'
Для курса валюты используется Exchange Rates Data API: https://apilayer.com/exchangerates_data-api.

7. get_share_price() модуль views.
Функция возвращает список со словарями цен на акции имеющихся в файле 'user_settings'
Для получения цен используется Share Price Data API: https://api.marketstack.com.

8. biggest_expenses() модуль reports.
Функция позволяет оценить по каким трем категориям за указанный месяц были самые большие траты
Для аназила принимает DataFrame, нужные год и месяц.
Возвращает словарь с названием категорий и суммой трат по каждой, в формате json.

9. def spending_by_category() модуль reports.
Функция принимает DataFrame, название категории и опционально дату в формате YYYY-MM-DD.
Возвращает список словарей с транзакциями по заданной категории за последние три месяца (от переданной даты)

10. profitable_cashback_categories() модуль services.
Функция принимает DataFrame с транзакциями, год и месяц, проводит анализ транзакций по кешбеку.
Возвращает словарь в формате json с категориями, по которым в данном месяце был получен кешбек,
и сумму кешбека в каждой категории за месяц.

### Проект содержит модуль decorators со следующими декораторами:

1. decorator_write_result_file()
Декоратор для функций-отчетов, который записывает в файл результат,
который возвращает функция, формирующая отчет.
Декоратор записывает данные отчета в файл с названием по умолчанию
(название функции для которой он был применен)

### В проект добавлены тесты для каждой функции, а также декораторов проекта в папке tests.
